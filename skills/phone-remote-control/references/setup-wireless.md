# 5 分钟接入：无线调试（推荐）

> **不需要数据线、不需要装任何 App、不需要 root。** Android 11 及以上都支持。
> 这是最省事的一条路，建议所有新用户先试它。

---

## 开始之前，先确认三件事

| 检查项 | 怎么确认 |
| --- | --- |
| 手机是 Android 11 或更高 | 设置 → 关于手机 → 看「Android 版本」 |
| 手机和电脑在**同一个 Wi-Fi** | 手机连的 Wi-Fi 和你电脑连的是同一个 |
| 电脑装了 adb | 终端执行 `adb version`，有版本号输出即可 |

> **Android 10 及以下？** 系统不支持无线调试，请走 [USB 接入](setup-usb.md)，
> 之后再按 [无线化](setup-usb.md#进阶把-usb-连接变成无线) 那节转成无线。

没装 adb 的话：

```bash
# macOS
brew install --cask android-platform-tools

# Ubuntu / Debian
sudo apt install android-tools-adb

# Windows
# 下载 https://developer.android.com/studio/releases/platform-tools
# 解压后把目录加进 PATH
```

---

## 第一步：打开开发者选项

1. 打开 **设置**，滑到底部点 **关于手机**
2. 找到 **版本号**，**连续快速点击 7 次**
3. 系统会提示「您现在处于开发者模式」
4. 返回设置主页面，进入 **系统** → **开发者选项**

> 小米/Redmi 在 **设置 → 我的设备 → 全部参数** 里点「MIUI 版本」7 次。
> 华为在 **设置 → 关于手机** 里点「版本号」7 次。

---

## 第二步：打开无线调试

在 **开发者选项** 里找到并打开：

- ✅ **无线调试**（Wireless debugging）——这是主角
- ✅ **USB 调试**（建议一起开，方便排错）

打开无线调试时，系统可能弹一个提示问是否允许在此网络上使用，选 **允许**。

> **⚠️ 小米/Redmi 用户注意**
> 打开无线调试时可能需要登录小米账号并插卡，这是 MIUI 的限制，不是本工具的要求。
> 如果卡在这一步，直接走 [USB 接入](setup-usb.md)，一样能用。

---

## 第三步：配对

保持手机停留在 **无线调试** 页面（**不要退出这个页面**），然后：

1. 在手机上点 **使用配对码配对设备**
2. 手机会弹出一个框，显示 **IP 地址和端口** 以及一个 **6 位配对码**
3. 在电脑上运行：

```bash
phone.sh pair
```

脚本会自动发现配对端口，然后提示你输入配对码：

```
→ 已发现配对端口 192.168.1.23:41234
请输入手机上显示的 6 位配对码: 123456
    Successfully paired to 192.168.1.23:41234 [guid=adb-XXXXXX-abcdef]
→ 配对成功，正在建立连接…
✓ 已连接 192.168.1.23:37001（已记住）
```

看到 `✓ 已连接` 就成了。

> **配对码过期？** 配对框只在一小段时间内有效。输入时若提示失败，
> 在手机上关掉弹框重新点一次「使用配对码配对设备」，拿到新码再试。
> 配对码里的 `IP:端口` 每次可能变化，所以**让脚本自动发现**，不要手动抄。

---

## 第四步：验证

```bash
phone.sh screen
```

正常输出类似：

```
屏幕: Awake | 锁屏: false | 前台: Window{... com.android.settings/.Settings}
```

再试一个真正的操作：

```bash
phone.sh shot --small /tmp/t.jpg    # 截图，应该能立刻看到手机屏幕
phone.sh nodes | head -20            # 读出界面上的文字和控件
```

## ⚠️ 必须知道的限制：重启后要重新开

**这是 Android 系统的设计，不是本工具的缺陷。**

| 情况 | 会发生什么 | 你要做什么 |
| --- | --- | --- |
| 手机重启 | 无线调试自动关闭（`adb_wifi_enabled` 被重置为 0） | 进开发者选项重新打开无线调试，然后 `phone.sh pair` |
| 换了 Wi-Fi 网络 | 端口可能变，连接失效 | `phone.sh pair` 重新配对 |
| 手机长时间休眠 | 连接可能断开 | `phone.sh pair` 或先唤醒手机 |

### 为什么要这样设计？

开启无线调试时系统会**随机生成**一个调试端口，并且只在本次开机期间有效。
这虽然带来一点不便，但它意味着：

- 别人无法通过固定端口 5555 猜到你的手机
- 每次重启后旧的调试授权自动失效

换句话说，**这是安全的代价，而安全更重要。**

### 想做到「开机自动连上」？

可以做，但需要额外配置。思路是：

1. 手机用 Tasker / MacroDroid 监听开机事件
2. 开机后自动打开无线调试（部分机型需要辅助功能权限）
3. 电脑端跑一个守护脚本，定期 `phone.sh pair` 尝试重连

如果这对你很重要，可以看社区里已有的方案，例如
[wireless-adb-reconnect](https://github.com/da-itda/wireless-adb-reconnect)，
它用的正是「mDNS 发现 + 自动连接 + 记住上次成功的策略」这套思路。

## 安全提醒

无线调试建立的是**局域网内**的调试通道，注意：

- ✅ 在家里 / 自己的 Wi-Fi 下用，没问题
- ✅ 调试授权是设备级的，别人电脑上配对不会复用你的授权
- ⚠️ **不要在公共 Wi-Fi（咖啡厅、机场）下开着无线调试**
- ❌ **绝对不要把调试端口暴露到公网**（不要在路由器上做端口转发到 5555）

需要在外网控制家里的手机？用 [Tailscale 方案](setup-tailscale.md) ——
它给你一条加密私有网络，不需要开任何公网端口。
